# Fourways

An isometric transport tycoon game: build rail lines, roads, ports and airports, carry passengers and
cargo between towns and industries, and grow your company against rival companies. Made with Godot.

## Download

Get the latest version from the **[Releases page](https://github.com/Neptrino/Fourways-game/releases/latest)**:

| System | File |
|---|---|
| Windows 10 / 11 (64-bit) | `Fourways-VERSION-windows-setup.exe` |
| macOS 11 or newer (Intel and Apple Silicon) | `Fourways-VERSION-macos.zip` |

### Windows

Run the installer. It installs for your user account only and doesn't need administrator rights.
The installer isn't code-signed yet, so Windows may show "Windows protected your PC": click
**More info**, then **Run anyway**.

### Mac

Unzip the file and drag **Fourways** into your Applications folder. The app isn't notarized by Apple
yet, so the first time macOS won't open it: go to **System Settings > Privacy & Security** and click
**Open Anyway** next to the message about Fourways. (On macOS 14 and older you can also right-click
the app and choose **Open**.)

## Updates

Fourways checks for a new version when it starts, downloads it in the background and offers to
restart to use it. You can switch this off in **Settings > Updates**. Occasionally a version needs a
fresh install: the game then shows a **Download** button that brings you back here.

Your saves, settings and mods are kept when you update or reinstall.

## Files in each release

Besides the installers, each release has `fourways-VERSION-*.pck` files and a `latest.json`. Those
are what the game downloads to update itself; you don't need them to install it.
