Make your first mod

Change the price of a sample locomotive and see it in the Fourways shop. All you need is the game and a plain-text editor.

  1. Download and unpack

    Download sample ZIP

    Unzip the download. It contains a first_locomotive folder with two files inside. mod.json identifies the mod and data.json defines the locomotive.

  2. Change the price

    Open data.json in a plain-text editor. Find this line under workshop_night_mail.

    "cost": 88000,

    Change 88000 to 45000. Keep the trailing comma and save the file as data.json.

  3. Enable the mod

    From the title screen, choose Mods → Open the mods folder. Move the unpacked first_locomotive folder there. Back in Fourways, click Look again and tick My first locomotive.

  4. Check the shop

    Start a new game in 1970. Press B or click Vehicle in the toolbar, then select Trains. The Owl Workshop Mail card should show $45,000. You can check the card before building any track or adding wagons.

If the locomotive is missing

  • Check that mod.json and data.json are directly inside the folder you moved into the mods folder.
  • If the Mods screen shows an error, check that you only changed the number in data.json. Save it, then click Look again.
  • The locomotive goes on sale in 1962. Check that your game is in 1962 or later.
